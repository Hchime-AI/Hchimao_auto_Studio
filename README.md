# Hchimao Studio V1.5.0

本地运行的 AI 自动打码 + 批量水印 + 封面 / 排序工具。**检测、打码、水印全在本机完成，图片不出你的电脑。**

界面是一个本地网页（`http://127.0.0.1:端口`），双击 bat 启动即可，不需要装数据库、不需要联网（除首次下载模型）。

**作者**：Hchime-AI × DSH ｜ **版本**：V1.5.0 ｜ **许可**：PolyForm Small Business 1.0.0（见 [LICENSE](LICENSE)）

> 本软件为独立开发项目：界面、仓库/工作区、AI 编辑、手绘引擎、批量水印、封面、排序、
> 账号与多语言、导出与缓存体系全部为本项目原创实现。
> 唯一的外部技术依赖是**打码模型应用部分**（NudeNet ONNX 检测器的加载与推理管线），
> 其版权归 NudeNet 作者所有，详见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 功能

### 1. 仓库（文件浏览）

左侧第一个入口。粘贴或输入任意本地路径，中央工作台按路径显示子文件夹与图片缩略图：

- 文件夹卡片（📁）+ 图片卡片，点文件夹进去，点 `⬆ 上一级` 退回
- 勾选图片（支持 Shift 连选、全选），也可以直接「导入本目录全部」
- 导入时**自动把选中的图片复制进程序自带的缓存目录**，母本一律不动

### 2. 工作区

导入进来的副本都收在这里，按「每次导入一个批次文件夹」组织，所以工作区根目录先看到文件夹，进去才是图片。

- **勾选文件夹 = 启用**：只有打过勾的文件夹，图片才会出现在 AI 编辑 / 手动编辑 / 批量水印 / 封面 / 排序的中央工作台里；勾多个就一起显示
- 可重命名工作区、删除工作区（只删副本）
- 三种导出：`导出 ZIP` / `导出所有` / `只导已打码`
- 导出的压缩包默认用**工作区名字**命名（比如 `打码结果_50张.zip`）
- 压缩包内部结构：**排过序** → 所有文件夹的图压平到一个目录、按序号排；**没排过** → 各批次保持独立子文件夹
- 工作区目录固定在 `cache/mirror/<时间戳-id>/`，启用状态 / 排序结果记在同目录的 `workspace.json` 里

### 3. AI 编辑（批量打码）

NudeNet（YOLOv8 ONNX，640m）本地推理，18 类可勾选，也可用 YOLO-World 填自定义英文词检测。

- 打码方式：马赛克 / 高斯模糊 / 纯色 / 图片遮挡（上传一张图盖住）
- 参数：强度、边缘外扩、检测阈值、推理分辨率（320 / 640 / 960 / 1280）
- 勾选要处理的图片 → 「开始打码」；结果自动成为该图的底层，可继续手绘补差
- 单张视图有「下载这张」；顶栏可整批导出

### 4. 手动编辑（手绘打码）

画布编辑器，五种笔刷：

| 笔刷 | 说明 |
|---|---|
| 色彩 | 纯色涂抹，颜色自选 |
| 马赛克 | 全局网格对齐的方块马赛克，走动画笔不会出现「一串球」 |
| 模糊 | 高斯模糊 + 径向羽化，边缘平滑 |
| 图片 | 用一张本地图片（如贴纸）当笔刷，不会上传到任何服务器 |
| 橡皮 | 只擦手绘笔迹，不动 AI 打码层 |

- 「码的粗细」只对马赛克 / 模糊有效
- 笔迹**逐图保留**，切图不丢；撤销 / 恢复按笔迹重放，不是像素快照
- 单张视图：滚轮在图片内缩放、图片外上下平移；滚动条固定在工作区外框，只认左键拖动

### 5. 批量水印

与打码共用同一个工作区、同一套勾选。

| 模板 | 行为 | 可调 |
|---|---|---|
| **四角任意**（默认） | 任选一个角（左上/右上/左下/右下），只打 1 个水印，距边界留边距 | 边距、字号、颜色、透明度、字体 |
| **单个角落** | 1 个水印，可在画布上直接拖动 | 拖动位置、字号、颜色、透明度 |
| **斜侧满屏** | 整屏斜向平铺 | 密度、角度、字号、颜色、透明度 |
| **滚动水印** | 横向滚动（可开「预览动画」） | 条数、速度、字号、颜色、透明度 |
| **弹动水印** | 画面内来回弹动 | 速度、字号、颜色、透明度 |

- 字体（黑体 / 宋体 / 等宽）、颜色、透明度在所有模板间**互通**，切换模板不丢
- **水印是固化的图层**：点「固化到选中 / 固化到全部」后这层就焊死在图上，之后再改参数只会往上**叠新的一层**，不会改掉已经确认的
- 右侧工作台底部会显示「这张图本次工作共有 N 个水印」，每层都能单独勾选 → 编辑 / 删除，也可以一键清空这张图的水印
- 长文字会自动缩字号，避免小图上压成一团

### 6. 封面工具

挑一张图，在它上面叠封面：

- 封面标题 / 副标题，内置「必看 / 精选合集 / 高清无水印 / 完整版 / 新作上线 / 私密推荐」等常用文案，点一下就填
- 位置（上 / 中 / 下）、对齐（左 / 中 / 右）、标题大小可调，自动加压暗渐变，白字压亮背景也看得清
- 装饰滤镜：原图 / 暖调 / 冷调 / 黑白 / 鲜艳 / 胶片 / 虚化
- 常用平台标识：b站 / 抖音 / 小红书 / 快手 / 微博 / YouTube / X / Instagram，四角任选、大小可调
- 确认后**复制出一张新图**（`原名_封面.png`）留在工作区里，原图一点不动；新图里已经带上你打的水印和马赛克

### 7. 排序工具

导出前用它决定文件夹里的顺序：

- 只在「全部」界面可用（排序模式下「单张」会被锁住）
- 勾选一张或多张卡片直接拖动，也可以用 `置顶 / 上移 / 下移 / 置底` 批量挪
- 「确认排序并改名」会**在磁盘上真的改名**成 `文件名_01.png`、`文件名_02.png`……，所以导出后的文件夹顺序就是你要的顺序（可重复执行，会按当前顺序重新编号）
- 「恢复文件名顺序」清掉排序结果，回到按文件名排
- **改名**：双击卡片上的文件名就能直接改（回车确认、Esc 取消）；也可以勾选后在右侧「重命名勾选的文件」里输入新名字点「应用改名」，勾多张会自动加 `_1`、`_2` 后缀。改名是**真的写在磁盘上**，仓库工作区里看到的都是新名字，同一文件夹的图通用
- **批量命名**：填前缀 / 起始号 / 位数，一键把勾选（或全部）图片改成 `前缀001`、`前缀002`……
- **删除勾选的文件**：删到程序内的回收站（`cache/trash`），不是直接抹掉
- **撤回 / 重做**：拖动、改名、批量命名、删除、确认排序都能撤，撤完还能重做（排序模式下 `Ctrl+Z` / `Ctrl+Shift+Z` 也走这套）

## 账号与语言

### 账号

第一次打开网页会先要一个账号：

1. 输入用户名（2–24 位）和密码（≥4 位）
2. **注册码**填 `Hchime-ai`（新账号都要这个码）
3. 创建成功后自动登录，之后打开网页直接进，不再要求登录

- 账号只保存在本机 `cache/auth/users.json`（PBKDF2-HMAC-SHA256 加盐哈希，不存明文）
- 左下角「设置」里可以**退出登录**，退出后要重新输账号密码
- 换一台电脑 / 换一个浏览器 = 重新建账号，账号不跨机同步

### 语言

左下角「设置 → 语言」可切 **简体中文 / 繁體中文 / 日本語 / English / 한국어 / Русский**：

- 第一次（新账号或新浏览器）选完语言后，语言标志（国旗）会飞进左下角的「设置」按钮里
- 之后打开网页按记住的语言显示，不再弹选择框
- 界面上的标题、提示、按钮、面板文字都会跟着切；面板里的长说明同样翻译

## 目录结构

```
.
├── app/                  程序主体
│   ├── webui.py          网页服务 + 全部前端（单文件）
│   ├── censor_core.py    打码核心（四种方式）
│   ├── yolo_world.py     开放词汇检测
│   ├── media_core.py     GIF / 视频逐帧
│   ├── auto_censor.py    命令行入口
│   ├── check_deps.py     依赖自检
│   └── selftest.py       自检脚本
├── models/               模型权重（不入库，见下）
├── cache/                运行产物（镜像 / 导出 / 缩略图，不入库）
├── tools/                start.ps1 启动脚本 / cleanup.ps1 清理残留进程
├── docs/                 文档与许可
├── 启动打码工作台.bat     双击这个启动
├── 清理所有实例(管理员).bat
├── THIRD_PARTY.md       第三方组件与模型说明
└── README.md
```

程序对目录做了健壮处理：`APP_ROOT` 取脚本上一级，模型按 `models/ → 脚本目录` 顺序找，所以**整个文件夹搬到别处仍能启动**。

## 依赖

### 运行环境

- Windows 10/11
- Python 3.9+（开发环境使用 3.11）
- 无需 GPU，CPU 推理

### Python 包

```
numpy
opencv-python
onnxruntime
Pillow
tokenizers        # 仅 YOLO-World 自定义类别需要
```

国内装依赖：

```bat
pip install numpy opencv-python onnxruntime Pillow tokenizers -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 模型

`640m.onnx`（约 99 MB）**没有放进仓库**（超过 GitHub 单文件限制，也不适合放权重）。首次启动会自动从镜像下载；手动下载地址：

- https://github.com/notAI-tech/NudeNet/releases/download/v3.4-weights/640m.onnx
- 国内镜像：https://hf-mirror.com/zhangsongbo365/nudenet_onnx/resolve/main/640m.onnx

下载后放到 `models\640m.onnx`。

## 启动

双击 **`启动打码工作台.bat`**：

1. 自动清理残留进程、检测端口（默认 8090，被占则顺延）
2. 检查依赖，缺什么装什么
3. 启动服务并打开浏览器

也可以手动：

```bat
python app\check_deps.py
python app\webui.py 8090
python app\webui.py 8090 --lan     :: 允许局域网访问
```

> 换了新版本后请在浏览器 **Ctrl+F5 强刷**，页面已带 `no-store`，但旧标签页仍可能吃到缓存。

## 遇到问题怎么办

**这个项目建议直接用 AI Agent（如 Claude Code / Codex / DeepSeek Harness 等能读写文件和跑命令的 Agent）来排查**，比手动翻代码快得多。把项目目录丢给 Agent，然后照着下面的话说：

```
项目在 <你的路径>，启动打码工作台.bat 之后页面打不开 / 功能不对，
请自己读 app/webui.py 排查，改完告诉我改了什么，别让我手动测试。
```

常见的几个自查点：

| 现象 | 先看什么 |
|---|---|
| 页面打不开 | 端口是否被旧实例占用；跑 `清理所有实例(管理员).bat` |
| 改了代码没生效 | Ctrl+F5 强刷；确认不是连到旧端口的旧进程 |
| 打码没效果 | `models\640m.onnx` 是否存在；依赖是否装全 |
| 导出里没有手绘笔迹 | 确认用的是「导出所有」而不是只导单张 |
| 报 `DLL load failed` | onnxruntime / opencv 版本与 Python 版本不匹配，重装 |

日志直接打在 bat 窗口里；崩了把窗口内容贴给 Agent 即可。
