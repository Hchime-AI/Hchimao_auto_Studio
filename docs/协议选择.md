# 协议选择（由作者决定）

仓库里**目前没有 LICENSE 文件**，也就是主程序许可由你定。
选好后按下面第 6 节的「落地步骤」放进去就行，代码不用动。

先说清楚一个前提：**主程序**（`app/webui.py` 全部界面与后端、工作区、AI 编辑、手绘引擎、
批量水印、封面、排序、账号与多语言、缓存与导出）是原创代码，你想怎么授权都行；
**打码模型应用部分**（NudeNet 权重与推理管线）另算，见 `THIRD_PARTY.md` 第 2 节。

配套建议（不影响代码，只是运营）：

- 仓库设为 Private，发行只给编译/打包后的版本；
- 加 EULA 弹窗（首次启动同意条款）——现在已有账号闸门，可以在同一张卡片下面加一行勾选；
- 授权走服务端租约（会员到期失效），做法见之前聊过的那套。

## 5. 双许可（开源版 + 商业版）

最常见的变现结构：

- 主程序以 **AGPL-3.0 或 GPL-3.0** 开源（社区版，功能完整）；
- 另售**商业许可**（闭源集成、免开源义务、优先支持）；
- `LICENSE` 写开源协议，`LICENSE-COMMERCIAL.md` 写商业条款与联系方式。

## 6. 落地步骤（选好后照做）

1. 把选定协议的正文存成根目录 `LICENSE`（第 2 条 Apache 的另存 `NOTICE`）。
2. 改 `README.md` 里两处：
   - 头部 `**许可**：待定（见「许可与署名」）` → 换成你选的协议名；
   - 「许可与署名」小节第一条 → 换成协议名 + 一句话说明。
3. 改 `docs/README.md` 的 License 徽章：
   `![License](https://img.shields.io/badge/License-由作者选择-lightgrey)`
   → `.../badge/License-MIT-green`（或 Apache--2.0 / BSD--3--Clause / Proprietary-red）。
4. `THIRD_PARTY.md` 保持不动（那是第三方组件说明，与主程序协议无关）。
5. 若选闭源收费：按 `THIRD_PARTY.md` 第 2 节处理模型应用部分，再发版。
